台灣蛇類概況

大多數蛇類是溫和、膽小的，遇到人的第一反應是逃跑而非攻擊。咬傷事件大多發生在人不小心踩踏、觸碰或驚嚇到蛇的情況下。

// 02

遇到一條蛇

⚠ 最重要的一件事

遇到蛇，不要試圖捕捉、驅趕或攻擊牠。大多數咬傷事件，都發生在人主動干擾蛇的情況下。

野外遇蛇時，請依照以下步驟應對：

Step 1 · 停下來

立刻停止移動，避免踩踏或進一步驚嚇到蛇。

Step 2 · 保持距離

緩慢後退，與蛇保持至少 2 公尺以上距離。蛇的攻擊距離通常不超過自身體長的一半。

Step 3 · 靜待離開

大多數蛇在沒有威脅的情況下，會自行離開。給牠時間和空間。

Step 4 · 繞道通過

確認蛇不在路上後，從遠處繞行通過，不要從蛇的正上方跨越。

蛇類是生態系中重要的捕食者，控制鼠類及其他小型動物的族群數量。住家附近出現蛇，通常代表周遭環境有豐富的食物來源（鼠類、青蛙等），而非蛇主動侵入。

透過環境整理（減少廢棄物堆積、清除雜草、填補牆縫）可有效降低蛇類進入住家的機會，是比捕捉驅趕更根本的解決方式。

// 住家防蛇建議

• 定期清理草叢、石堆與廢棄物堆積，減少蛇類藏匿空間
• 封堵地基縫隙、排水孔與牆面裂縫
• 夜間於庭院或戶外移動時，先開燈確認環境
• 家中若發現蛇，勿自行捕捉，可聯繫農業局協助

// 野外活動指南

• 行走時走在明顯路徑上，避免踩入草叢或石縫
• 需要打草驚蛇，不踩踏落葉堆
• 夜間活動務必攜帶手電筒，照亮前方地面
• 穿著包鞋、長袖
• 不隨意捕捉不認識的生物

// 03

破除迷思

關於蛇類，社會上流傳許多錯誤觀念，這些迷思往往讓人做出危險或不必要的行為。

❌ 迷思 01 · 蛇會主動攻擊人

蛇類對人類沒有主動獵食的意圖，絕大多數咬傷事件都發生在人不小心驚嚇或踩踏到蛇的情況下。蛇在感受到威脅時的第一反應是逃跑，咬人是牠們萬不得已的最後防禦手段。

❌ 迷思 02 · 看到蛇就要打死牠

大多數蛇遇到人的第一反應是逃跑。主動攻擊蛇反而是大多數咬傷事件的真正原因。遇蛇保持距離、讓牠自行離開才是正確做法。

❌ 迷思 03 · 花紋鮮豔的蛇才有毒

外觀鮮豔程度無法判斷是否有毒，不認識的蛇一律保持距離。雨傘節、龜殼花等毒蛇外觀樸素；紅竹蛇、高砂蛇、紅斑蛇等無毒蛇外表鮮豔。

❌ 迷思 04 · 毒蛇的頭一定是三角形

頭部形狀不是辨識有無毒性依據，大多蝮蛇科的毒蛇因具有頰窩的構造，使頭部呈現三角形的頭型，其他科別的劇毒蛇種，如蝙蝠蛇科的眼鏡蛇、雨傘節，頭部為橢圓形。且對頭型的認定是很主觀的意識，部分無毒蛇在受驚時也會將頭部壓扁呈三角形。

❌ 迷思 05 · 台灣的眼鏡蛇都是被放生的外國眼鏡蛇

台灣的眼鏡蛇為中華眼鏡蛇（Naja atra），是台灣本土的原生蛇種，廣泛分布於全台低海拔山區與農田。外國的毒蛇是禁止輸入台灣，就算是早年留下的寵物蛇，數量不大，加上許多原產地位於東南亞，在台灣要能度冬並建立族群不太可能。在野外看到非原生種蛇類多半是寵物逃逸，可連絡農業處或動保處等相關單位處理。

// 辨識小提醒

台灣有多種無毒蛇外觀與毒蛇相似，保持安全距離互動、靜待他們離開，不要隨意捕捉不認識的動物。

// 05

易混淆毒蛇與無毒蛇

台灣有數種無毒蛇與毒蛇外觀高度相似，野外遇蛇時切勿憑外觀輕易判斷是否有毒。以下為三組常見的易混淆蛇種。

// 組一 · GROUP 01
⚠ 有毒
赤尾青竹絲
Trimeresurus stejnegeri
• 頭部明顯呈三角形（頰窩）
• 尾巴為赤紅色
• 眼睛為橘紅色
• 體側有白色或白紅色縱線
✓ 無毒
青蛇
Cyclophiops major
• 頭部較圓、無頰窩
• 尾巴為綠色或淡黃色
• 眼睛為黑色
• 體側無縱線紋路
// 組二 · GROUP 02
⚠ 有毒
龜殼花
Protobothrops mucrosquamatus
• 頭部明顯三角形（頰窩）
• 眼後有深棕色縱帶
• 背部不規則棕色斑塊
• 腹鱗花色斑塊，尾部磚紅色調
✓ 無毒
擬龜殼花
Oligodon formosanus
• 頭部較圓、無頰窩
• 無眼後縱帶
• 背部斑紋較規則、對稱
• 體型較細小
// 組三 · GROUP 03
⚠ 有毒
雨傘節
Bungarus multicinctus
• 背上有六角形大鱗片（明顯脊稜）
• 黑白環紋間隔清晰均等
• 白色環紋較細
• 尾部較短
✓ 無毒
白梅花蛇
Lycodon ruhstrati
• 無明顯背部脊稜
• 白色環紋較寬、不均等
• 頭部較扁平
• 體型較細長
// 野外判斷原則

不認識的動物，一律保持距離、不觸碰、不隨意捕捉。

// 06

野外你該認識的其他蛇

除了六大毒蛇，台灣野外還有許多值得認識的蛇種，牠們在生態系中扮演重要角色，大多數對人類無害。

// 無毒蛇 · NON-VENOMOUS
王錦蛇
Elaphe carinata
• 台灣體型最大的無毒蛇
• 背部黑黃花紋，鱗緣黃色
• 廣泛分布於平地至中低海拔山區
南蛇
Ptyas mucosa
• 行動迅速、移動距離長
• 體色多為黃褐至橄欖綠
• 常見於平地農田、草叢
• 以鼠類、蜥蜴、蛙類為食
黑眉錦蛇
Elaphe taeniura
• 眼後有明顯黑色縱帶為辨識特徵
• 攀爬能力強，常見於樹上或屋舍
• 四大家蛇之一 · 保育類野生動物
• 對控制鼠類族群有重要貢獻
紅斑蛇
Dinodon rufozonatum
• 體色為紅褐色帶黑色橫帶
• 夜行性，常見於平地與低山
• 以蜥蜴、小型蛙類為主食
// 微毒蛇 · MILDLY VENOMOUS
後溝牙蛇類，毒液對人類影響輕微，一般情況不具生命威脅，但仍建議避免接觸。
茶斑蛇
Psammodynastes pulverulentus
• 體色為茶褐色帶深色斑紋
• 頭部略呈三角形，易與毒蛇混淆
• 日行性，常見於山區溪流附近
• 後溝牙，對人毒性極低
大頭蛇
Boiga kraepelini
• 頭部明顯寬大，眼睛大而突出
• 善於攀爬樹木
• 以蜥蜴、小型蛙類為主食
• 後溝牙，對人毒性極低
// 登山你該認識的蛇 · MOUNTAIN HIKING
中高海拔山區特有或偏好棲息的蛇種，登山前建議認識。
✓ 無毒
鈍頭蛇
Pareas formosensis
• 頭部寬扁、吻部鈍圓為主要特徵
• 夜行性，棲息於中高海拔潮濕山區
• 特化以蝸牛、蛞蝓為主食
• 性情溫和，對人無威脅
⚠ 劇毒
菊池氏龜殼花
Protobothrops kikuzatoi
• 台灣特有種，棲息於中高海拔山區
• 外觀與龜殼花相似，體色偏深
• 出血毒，毒性強烈
• 族群稀少，屬保育類野生動物
// 07

外來入侵蛇類

外來種蛇類可能透過寵物貿易、貨物運輸等管道進入台灣，對本土生態系造成潛在威脅。目前台灣已記錄一種外來入侵蛇類。

白枕白環蛇 · Lycodon capucinus

科：黃頷蛇科（無毒）
俗稱：變色蛇、家蛇
原產地：東南亞
入侵現況：屏東縣東港一帶，目前狀況還不明朗。

• 體色多變，幼蛇頸部有白色環紋（成體漸消）
• 游獵型，夜間主動搜索獵物
• 常出沒於住家、倉庫、農舍附近
• 以壁虎、小型蜥蜴為食，適應力極強
• 雖無毒，但其擴散可能壓迫本土蛇類的生態棲位

⚠ 發現疑似外來種蛇類請勿自行捕捉，可通報林業及自然保育署
